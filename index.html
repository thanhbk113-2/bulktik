📘 Cài đặt đăng Facebook Page
Chỉ đăng được lên Facebook Page (Facebook không cho đăng tự động lên trang cá nhân).
Cách lấy token: vào Graph API Explorer → chọn app của bạn → thêm quyền pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_engagement (bắt buộc để bình luận) → Generate Access Token (tick chọn Page khi Facebook hỏi) → copy token. Page ID xem trong phần Giới thiệu của Page. Nếu dán token cá nhân, hệ thống tự đổi sang token của Page. Bấm Kiểm tra token để chắc chắn trước khi đăng.
Lưu ý: token tạo từ Graph API Explorer chỉ dùng được khoảng 1–2 giờ. Để bình luận của bài hẹn giờ tự đăng được, hãy nhập App ID + App Secret (trong Cài đặt → Thông tin cơ bản của app ở developers.facebook.com) rồi bấm Kiểm tra token — token sẽ được đổi sang loại dài hạn.
Token được lưu trên trình duyệt này. Với bài hẹn giờ có bình luận, token của Page được lưu tạm trên máy chủ đến khi đăng xong bình luận rồi xoá.
